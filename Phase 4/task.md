Phase 4: Final Research Paper and Complete Project Submission
For Phase 4, continue using the same Overleaf project and template from Phase 2. Complete and update all components specified in the .tex template, incorporating your final methodology, experimental results, analysis, and research contributions.

Your final report should follow the structure and quality demonstrated in the example research report provided.

Paper length: Minimum 8 pages and maximum 20 pages, including references and appendices.

1. Submission Requirements
   Submit one ZIP file containing:

Complete Overleaf project: Download the entire Overleaf project, including all bibliography, figures, and supporting files. Refer to the attached screenshot for instructions on downloading the complete Overleaf project in zip format.

Final paper PDF: Include the complete compiled research paper. Refer to the attached screenshot for instructions on downloading the PDF from Overleaf.

Research poster (.pptx): Include the final single-slide PowerPoint research poster prepared for Phase 3.

Source code: Include all implementation, training, testing, and evaluation code. Your source code will be used to verify and evaluate your experimental results, so organize all executable files and dependencies in a dedicated folder.

Experimental results: Include numerical results and supporting files, such as .csv or .txt.

Figures: Include all research graphs and figures in .eps or .png format.

README file: Provide instructions explaining the project structure, dependencies, dataset sources, code execution, and steps to reproduce the results.

Supporting files: Include any additional configurations, scripts, or files required for reproducibility.

3. Individual Submission Requirement (Mandatory)
   Every team member must individually submit the complete project ZIP file to the Phase 4 Canvas Assignment.

Each member must submit the entire project, not just the files they personally worked on.

All team members may submit identical project contents, but each ZIP filename must include the respective student's NetID.

A submission by only one team member does not count as a submission for the other members.

Ensure every member has a complete copy of the final research paper, poster, source code, results, and supporting materials.

This requirement ensures that every team member has access to and retains the complete research project independently, rather than relying on another member for project files.

Important
Ensure that all template components are completed, experimental results are genuine, and the submitted source code and supporting files are sufficient to verify and reproduce your research.

Only complete ZIP submissions containing all required project materials will satisfy the Phase 4 submission requirements.
