Part 1. Set up the slide

The three moves you will repeat

Set size and position. Click the object, then Shape Format (or Picture Format) > Format Pane > Size & Properties icon. Open Size and Position and type the four numbers. Position is From: Top Left Corner. Turn Lock aspect ratio off for shapes and text boxes, and leave it on for pictures.

Add a text box. Insert > Text Box, drag anywhere on the slide. Press Copy text here and paste with Cmd+V (if PowerPoint offers paste options, pick Keep Source Formatting). In Size & Properties > Text Box pick Do not Autofit and check Wrap text in shape. Set the size and position last, after pasting. Then click its edge and check that the font and size match the number given here.

If the paste loses formatting, select the box, set Arial and the size, black text, line spacing 1.0, 0 pt before and after. Click the bullets button on the lines that have bullets here, and bold the words that are bold here.

Add a picture. Insert > Picture from File > Phase 3/Poster/Simple/figures. Type the width with the aspect ratio locked and the height fills itself in (within 0.01). Then type the position.

Part 4. Motivation

  1. Foundation models are adapted to skin images with linear probing (LP) or LoRA to find lesions that may be malignant. If a model gives a 20% risk, about 20% of those lesions should be malignant (calibration).


    Risks are usually calibrated on clean images, but real photos can be blurry, noisy, or badly lit.


    Gaps in past work:

    • Shift-aware methods like DAC [1] and AAR [2] are fit for the average, not the worst-off patient group.
    • Group-aware methods like Cluster-Focal [3] assume test images look like the calibration images.
    • As far as I know, no published medical imaging study measures group calibration by corruption severity or by adaptation method.
    WidthHeightHorizontalVertical

  2. Research question: Can a calibrator that sees only the image keep the worst-off group calibrated under new corruptions, and does it matter if the model uses LP or LoRA?

    Goal: Build a calibrator fit for the worst group and test when it helps.

Part 6. Methods

  1. GR-SATS (group-robust shift-aware temperature scaling):

    Corrects the predicted risk after training. The model is not changed. The challenge is that the patient's group is unknown at test time and some groups are small (skin types V-VI have only 32 cancers).

Part 9. Conclusions and Future Work

  1. Conclusions:

    • The answer is partly yes. GR-SATS has the lowest WG NLL, but it still goes up with severity.
    • DAC with the same worst-group loss ties GR-SATS (0.397 and 0.398), so the gain over DAC comes from the loss.

    Limitations:

    • Most of the gain is on noise. Without noise it drops from 0.044 to 0.009. Patients under 60 get a higher NLL, and clean ECE is higher than clean TS.
    • Nemenyi does not separate GR-SATS from DAC, AAR, multi-domain TS, cluster-wise TS, or TS with noise.
    • Not run: official DAC and AAR code (I reimplemented both), TS with textures, ImageNet ViT, full fine-tuning, a from-scratch rerun

    Future Work:

    • Real hospital and camera shifts, and a fit that limits the cost to other groups
